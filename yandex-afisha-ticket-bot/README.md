# Yandex Afisha ticket watcher

Следит за одной страницей мероприятия на `afisha.yandex.ru` и присылает
уведомление в Telegram, когда там появляются билеты. Бот **не покупает
билеты сам** — только уведомляет, чтобы вы успели купить вручную.

## Установка

```bash
cd yandex-afisha-ticket-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Настройка `.env`

1. `EVENT_URL` — ссылка на страницу конкретного мероприятия на afisha.yandex.ru.
2. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather),
   получите `TELEGRAM_BOT_TOKEN`.
3. Напишите своему боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<TOKEN>/getUpdates` и найдите там
   `"chat":{"id": ...}` — это `TELEGRAM_CHAT_ID`.
4. При желании поправьте `CHECK_INTERVAL_SECONDS` (по умолчанию 90 секунд —
   не ставьте слишком маленький интервал, чтобы не долбить сайт запросами).

## Запуск

```bash
python bot.py --once   # разовая проверка, удобно для теста
python bot.py           # постоянный цикл проверки
```

## Если бот всегда пишет "unknown"

Разметка страницы у Яндекс Афиши может отличаться от той, на которую
рассчитаны шаблоны в `availability.py`. Сохраните HTML страницы и
посмотрите, какими словами там на самом деле обозначено наличие/отсутствие
билетов:

```bash
python bot.py --dump-html
```

Это создаст `page.html`. Найдите в нём фразы про билеты и добавьте/поправьте
регулярки в `AVAILABLE_PATTERNS` / `UNAVAILABLE_PATTERNS` в `availability.py`.

## Ограничения и предупреждение

- Это скрипт для личного использования (мониторинг одной страницы), а не
  для массового парсинга сайта или обхода защит.
- Автоматическая покупка билетов сюда сознательно не входит: она требует
  ввода платёжных данных, обхода капчи/антифрод-систем и с высокой
  вероятностью нарушает пользовательское соглашение Яндекс Афиши — вплоть
  до блокировки аккаунта.
- Не уменьшайте `CHECK_INTERVAL_SECONDS` слишком сильно — частые запросы
  могут привести к блокировке по IP.
- Определение наличия билетов основано на текстовых паттернах и может
  давать ложные срабатывания/пропуски при изменении вёрстки сайта —
  относитесь к уведомлениям как к подсказке, а не гарантии.
